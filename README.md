# 🚗 Geely Atlas FX11 (Boyue L, G636) — CarPlay / Bluetooth: баги и фиксы

📖 Для Geely Cityray (G426) есть отдельный репозиторий: **[GeelyCityray-AppInstaller](https://github.com/vyunolbek/GeelyCityray-AppInstaller)**

**Без root-прошивки. Без риска для машины.** На этой прошивке (FX11/G636, ECARX) ADB доступен **по сети** без каких-либо активаций — этим и пользуемся.

**Кому подойдёт:** владельцам Geely Atlas 2024 (FX11 / Boyue L) со штатным беспроводным CarPlay, у которых:
- после CarPlay машина **не подключается автоматически** к телефону по Bluetooth;
- беспроводной CarPlay **отваливается** (глушилки, тоннели) и **не переподключается** — спасает только «отвязать и привязать телефон».

---

## 🔍 Что здесь нашли

Оба поведения разобраны **до конкретных строк кода** (декомпиляция системных APK прошивки). Кратко:

| Баг | Причина (по коду) | Лечение |
|---|---|---|
| **BT-авто-коннект мёртв после CarPlay** | Баг в `CarPlayService`: ключ `key_carplay_disconnect_address` пишется при беспроводном CarPlay, но чистится при отключении **только для проводного** (`capaType == 0`). Пока ключ непустой, сервис BT пропускает авто-коннект целиком | Одна команда adb (скрипт `fix-carplay.sh`) |
| **CarPlay не переподключается сам** | Переустановка собрана на одноразовых таймерах (окно 15 сек, без цикла повторов), `mConnecting` залипает, `isWifiApEnabled()` молча глушит reconnect, и телефон матчится по **рандомизированному Wi-Fi MAC iPhone**, который ротируется | `fix-carplay.sh` вместо перепривязки + мониторинг `cp-monitor.sh` + фикс на iPhone |

Подробный разбор с выдержками из кода — в **[DETAILS_TECH.md](DETAILS_TECH.md)**.

## 🧰 Что понадобится

| Что | Примечание |
|---|---|
| Ноутбук с **Linux** (или macOS) | проверено на Ubuntu |
| **adb** | `sudo apt install adb` |
| Ноутбук и машина **в одной Wi-Fi сети** | машина подключена к точке доступа (например OLAX-роутер) |

> ⚠️ Все работы делаются со **своей** машиной и на свой страх и риск. Ничего в системную память не пишется — только чтение состояния, чистка одного settings-ключа и перезапуск сервисов.

## 🔓 Шаг 0. ADB — на этой машине он и так есть

На FX11/G636 (userdebug-сборка) `adbd` слушает **TCP 5555** без всяких инженерок и QR-кодов:

```bash
sudo apt install adb
# узнай IP магнитолы (см. ниже) и:
adb connect 192.168.100.100:5555
adb devices        # должно показать device
```

**Как узнать IP ГУ:** он виден на роутере/точке доступа в списке клиентов. В типичной схеме с OLAX-роутером машина получает адрес вида `192.168.100.x` (проверено: `192.168.100.100`). Если IP не знаешь — `fix-carplay.sh` просканирует подсеть сам.

> Инженерное меню (`*#32279` — на FX11 `#*32279`, звёздочка и решётка наоборот) для ADB тут **не нужно** — в меню нет пункта ADB switch, как на Cityray. Внутри: Настройка, Обновление, Журнал, Версия, TCAM, Конфигурация CC (только чтение, CC = Customer Customization), PSD, Смена языка.

## 🩹 Шаг 1. Починить BT-авто-коннект (одна кнопка)

```bash
./scripts/fix-carplay.sh
```

Скрипт (Linux, bash):
1. Находит машину в сети (или берёт IP из аргумента) и подключается по adb;
2. получает root (`adb root` — на userdebug работает);
3. чистит залипший ключ `key_carplay_disconnect_address`;
4. перезапускает CarPlay-сервис (его `reconnectOnStart()` поднимает сессию по последнему устройству, **не трогая bond**) и DCM;
5. перезапускает BT-стек.

Проверено: после чистки ключа и рестарта BT машина **сама** подняла A2DP + HFP + AVRCP с iPhone.

**⚠️ Баг повторится** после каждого использования беспроводного CarPlay — просто запускай скрипт снова (10 секунд).

## 📡 Шаг 2. Мониторинг (найти причину отвала)

```bash
./scripts/cp-monitor.sh          # пишет carplay-ГГГГММДД-ЧЧММСС.log
```

Останов — `Ctrl+C`. Файл — фильтрованный logcat (`ReconnectManager`, `BluetoothManager`, `DeviceConnectService`, `BTS.ConnectionPolicy` и др.). По логам видно, какое условие убило переподключение (см. разбор в DETAILS_TECH).

## 📱 Что сделать на iPhone

Код матчит телефон по сохранённому Wi-Fi MAC, а iPhone **ротирует private-адреса**:

1. *Настройки → Wi-Fi → сеть машины → Частный адрес Wi-Fi → **Фиксированный*** (iOS 18+). Убирает самый вероятный источник поломки матчинга.
2. Не привязывай CarPlay и BT «наживую» в дороге: аккуратно отвяжи (*Настройки → Основные → CarPlay → Geely → Забыть этот автомобиль*), потом заново привяжи BT.

## ❗ Границы

- **Пропатчить и подменить APK нельзя**: системные приложения подписаны приватным платформенным ключом Autolink и живут в shared UID `android.uid.system` — переподписанный пакет будет отброшен при загрузке. /system защищён dm-verity (AVB).
- Конфигов для reconnect нет: все таймауты захардкожены (15 сек окно, 3 попытки, 10 сек reconnect). Persist-свойства — только включатели (`persist.autolink.carplay.enable` и т.п.).
- Радикальное решение — патченная прошивка **GMC** (GMCustoms) для FX11: там эти баги починены вендорским путём, но это платная замена системы.
